- Deep links function correctly
- Browser refresh preserves state

- One-hand usability
- Primary CTA reachable
- Search reachable
- Close actions reachable
- Chat input reachable

# Touch Testing

- Minimum 48x48 tap target
- Swipe gestures work
- Long press works
- Drag and drop works
- No hover-only functionality

# Atlas Testing

- No horizontal scroll
- Zoom performance smooth
- Expandable chapter cards
- Search highlighting visible
